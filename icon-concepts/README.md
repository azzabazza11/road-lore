# Passenger Tales icon concepts

Four quick SVG directions for the app icon:

1. `passenger-tales-option-1-road-wave.svg`  
   Road + voice wave. Best fit if you want "AI road stories" to read instantly.

2. `passenger-tales-option-2-pin-book.svg`  
   Map pin + book. Best fit if you want "place stories" over "driving tool".

3. `passenger-tales-option-3-pt-monogram.svg`  
   PT monogram badge. Best fit if you want something more brand-like and less literal.

4. `passenger-tales-option-4-car-trail.svg`  
   Car + story trail. Best fit if you want something friendlier and more playful.

These are vector placeholders you can tweak further or use as art direction for a later generated/rendered icon.
